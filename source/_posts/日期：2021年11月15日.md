主要知识点及其实现流程或步骤、注意事项（可多项）：

1.静态修饰符（static）作用:防止被实例化

2.访问修饰符

共有的 public ：别的项目，都能访问到

内部的 internal: 只允许被内部访问到，外部工程访问不到

私有的 private:别的项目访问不到， 只有本类代码才能访问

保护的 protected：只能类或者派生类才能访问

3.继承修饰符（new，unsafe）

4.只读修饰符 (readonly)

5.线程修饰（volatile）

1.构造函数

方法：

```c#
public class aoligie
{
    public int a ,b ;
    public  aoligei(int a)//因为无参构造函数是struct固有的，所以在定义构造函数时不能定义无参数的构造函数
    {
        a = a;
    }
    public  aoligei(int a,int b) : this (a)//如果没有有加静态修饰符号，那么构造函数可以被构造函数调用的
    {
        b = b;
    }
}
```

# 首先

#### 创建远线程    之前呢   需要先   获取指定      **进程 **    的PID    也就是**句柄**。

#### 那么如何获取句柄捏？

#### 接下来就需要用到一个函数

```c++
//这个函数原理  先获取系统权限  然后在去获取指定进程的
HANDLE OpenProcess(      
   DWORD dwDesiredAccess,1.	指定需要对该进程的操作码      一般用    PROCESS_ALL_ACCESS    就能全部操作了
   BOOL  bInheritHandle, 2.	参数指定为TRUE，能被当前的子进程继承否者不可以
   DWORD dwProcessId     3.	指定目标进程的ID
);
如果成功就返回进程的PID,否则返回NULL
```

# 然后

#### 上面已经   **获取到了进程的句柄**，接下来**在该进程里面来强制创建一个线程**来**执行我们需要用到的功能以及函数和动静态链接库**！！！！！

#### 那么用什么函数去强制创建一个线程呢？

#### 接下来不就不多说了：

```c++
//函数原理就是   把目标进程的PID,所需要执行的功能放进去  返回一个新线程句柄
HANDLE CreateRemoteThread(
  [in]  HANDLE                 hProcess,               1.要创建进程的句柄   //目标进程的PID
  [in]  LPSECURITY_ATTRIBUTES  lpThreadAttributes,     2.句柄的继承    //默认为NULL  
  [in]  SIZE_T                 dwStackSize,            3.堆栈大小     // 默认为0       表示都一样
  [in]  LPTHREAD_START_ROUTINE lpStartAddress,         4.即将执行函数的地址   比如    某个功能 //自定义的函数  
  [in]  LPVOID                 lpParameter,            5.传递给子线程自定义函数的值   //0为无限制 （也叫做内存地址）
  [in]  DWORD                  dwCreationFlags,        6.控制运行的参数     //默认填0   创建就直接运行   
  [out] LPDWORD                lpThreadId              7.返回的值          //默认值为NULL
);
如果成功就返回新现成的句柄，否者返回NULL
```

#### 创建好以后，那么就能执行想要注入的东西了，填写相应的函数就ok。

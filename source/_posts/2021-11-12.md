1.namespace嵌套以及using导入库的要素

```c#
1.namespace 嵌套关系

比如：
namespace text1      // 
{
    namespace text2
    {
	class a{}
    class b{}
    }
    class a{}
    class b{}
}


在main函数里面访问的text2的时候是这样的
static void Main(String[] args)
{
    text1.text2.a;
    text1.text2.b;
    也可以直接
        text2.a;
        text2.b;
}

using 导入库的也是根据这样一种原理来的
    比如using text1.text2
    就能访问text2 里面的东西
```

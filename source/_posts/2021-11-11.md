###### 1.switch循环

```c#
int a = int.parse(Console.ReadLine());
switch(a)
{
    case 1： 
        Console.WriteLine("一"); 
        break;
    case 2：  
         Console.WriteLine("二"); 
        break;
    case 3:   
        Console.WriteLine("三"); 
        break;
    case 4:    
        goto case 1;          //这个跳转到语句1  也可以  goto default；
        break;
    default : 
        Console.WriteLine("五"); 
        break;
} 

```

##### 2.foreach循环

```c#
int[] aa = new int[]{12,34,45,56};
foreach(int a in aa)//类型    变量    in   数组名
{
    Console.WriteLine(a);
}
```

出现问题（训练过程中出现的任何问题，不分大小，可多选）：

问题一：没搞懂foreach参数里"in"的意思

问题测试/解决方法（分析问题引发的可能性及相应的测试和解决办法，注明解决结果）：

后来慢慢理解就知道了，in 在英语里面就是“在里面”的意思所以在程序里面的意思就是读取里面的值依次循环
